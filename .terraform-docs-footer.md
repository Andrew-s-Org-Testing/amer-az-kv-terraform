## Pre-Commit Installation
Before you can run hooks, you need to have the pre-commit package lanager installed.

Using plp:
```
pip install pre-commit
```

Non-administrative installation:

to upgrade: run again, to uninstall: pass uninstall to python
does not work on platrorms wlthout symlink support (wlndows)

```
curl https://pre-commit.com/install-local.py | python
```

Afterward, `pre-commit --version` should show you what version you're using.

## Installing Other Pre-Commit tools
detect-secrets and checkov need their own installations
```
pip install detect-secrets \
pip install checkov
```

if the repo does not contain a .secrets.baseline, please generate one with
`detect-secrets scan > .secrets.baseline`
to scan the repo and add a baseline of potential secrets that could be found in the repo
